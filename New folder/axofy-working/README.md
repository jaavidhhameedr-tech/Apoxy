# Axofy — Supabase-connected prototype

The supplied Axofy UI is preserved as the visual source. `index.html` is now connected to the Supabase project configured for this build.

## Included
- Supabase email/password sign-in
- Email/password account creation through the existing Get started control
- Password reset
- Google OAuth call
- Apple OAuth call
- Persistent Supabase session
- Profile creation on first sign-in
- Onboarding persistence for role, goals, subjects and quiz answer
- Per-user learning progress and tasks schema with RLS

## OAuth dependency
Google and Apple buttons are implemented with Supabase OAuth. Their provider credentials still have to be enabled in the Supabase Auth provider settings; those credentials come from Google Cloud and Apple Developer and cannot be generated by the database connection.

## Run
Open `index.html` in a browser or serve this folder with any static web server.
